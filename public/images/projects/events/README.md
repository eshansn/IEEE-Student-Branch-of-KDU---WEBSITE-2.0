Inside each folder, use:

- `<FilenameBase>Cover.webp` for the project-card thumbnail.
- `<FilenameBase>Main.webp` for the large image at the top of the project detail page.
- `<FilenameBase>1.webp`, `<FilenameBase>2.webp`, `<FilenameBase>3.webp`, and so on for gallery images.

PNG or JPG files can also be used; keep the same filename stem and update the extension when connecting the image path in `src/components/sections/Projects/eventProjects.ts`.
